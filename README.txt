DRISHTI CHOPRA PORTFOLIO

PROJECT FILES:

1. index.html
   Main website structure.

2. style.css
   Website styling, layout, animations
   and responsive design.

3. script.js
   Interactive terminal and skill filters.

4. Drishti_Chopra_Resume.pdf
   Downloadable resume.


HOW TO RUN:

Step 1:
Open the portfolio folder in VS Code.

Step 2:
Open the terminal.

Step 3:
Run:

python3 -m http.server 5500

Step 4:
Open your browser.

Visit:

https://drishti-chopra-portfolio.onrender.com/


IMPORTANT:

Keep all five files in the same folder.

Do not rename script.js or style.css.
Keep the terminal running while viewing
the website.
